## 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字？

一開始 `people = "4"` 有加引號，所以 Python 把它當成文字（`str`），不是數字。
計算每人費用時，需要用總金額除以人數，文字不能拿來做除法，所以要先用
`int(people)` 轉成整數 `4`。另外，文字的 `"4" + "1"` 會變成 `"41"`，
數字的 `4 + 1` 才會是 `5`，可見看起來像數字不代表 Python 當它是數字。

### 問題二：如果先扣折價券，再計算服務費？

第一組如果先扣折價券：1,200 − 100 = 1,100 元，再用 1,100 元算 10% 服務費，
服務費是 110 元，總額是 1,100 + 110 = 1,210 元。
題目規定的算法是用原始餐費 1,200 元算服務費（120 元），
總額是 1,200 + 120 − 100 = 1,220 元。
兩種算法的服務費基準不同，差了 100 × 0.10 = 10 元。
